# Kitchen-web

Kitchen iOS 应用的**公开**静态页面：隐私政策、产品介绍、支持（与主工程 `Kitchen` 私有仓库中 `docs/` 保持一致，由脚本或手动同步）。

## GitHub Pages

仓库 **Settings → Pages**：Source **Deploy from a branch**，Branch **main**，Folder **/**（根目录，勿选 `/docs`）。

部署后地址示例：`https://harry-linn.github.io/Kitchen-web/`（以你的 GitHub 用户名为准）。

| 路径 | 内容 |
|------|------|
| `/` | 隐私政策（`index.html` + `PRIVACY_POLICY.md`） |
| `/home.html` | 产品介绍（含 `app-icon.png` 真机图标） |
| `/support.html` | 支持 |
| `/app-icon.png` | App Store 图标资源 |
